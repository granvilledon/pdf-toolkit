# PDF 目录（书签）制作完整规范 v2.0

适用范围：`桌面\2027法硕备考` 下所有 PDF 教材/题集的书签生成与验收。
v2.0（2026-09-26）：整合 Project MUSE 出版规范与三轮实践全部经验，取代 v1.x，作为剩余 66 本的唯一标准。

---

## 〇、规范依据与本地化例外

参照 **Project MUSE（约翰霍普金斯大学出版社电子书平台）Ebook PDF Bookmarking 规范**，逐项对照并做本地化调整：

| MUSE 规范 | 本标准 | 说明 |
|---|---|---|
| 封面必须单独加书签 | ✅ 采纳 | L1 封面 |
| 目录必须单独加书签 | ✅ 采纳 | L1 目录页 |
| 次要前置页（版权页/题献/致谢等）默认合并一条；**被印刷目录列出的前置页必须单独列** | ✅ 采纳 | 本套书只出现序言/前言/使用说明，均单列（目录里都有） |
| 子小节（subchapter）从不单独加书签 | ⚠️ **例外不采纳** | MUSE 面向文学/学术电子书；备考工具书需精确到"节"定位考点，**L3 节级书签保留** |
| 正文 部/章 必须分列 | ✅ 采纳，并扩展 | 本套书在部之上还有"课/编/部分/学科/题型"层，见第一节 |
| 参考文献/索引/术语表必须分列 | ✅ 采纳 | 对应附录/附件 |
| 次要后页（作者简介等）合并 | ✅ 采纳 | 本套书暂未出现 |

## 一、书签层级总表（自上而下，书中有什么层就必须有什么层）

| 层级 | 内容 | 页码指向 | 规则 |
|---|---|---|---|
| L1 封面 | 封面（第 1 页） | p1 | 第 1 页是完整封面的书**必须加**、排最前。**第 1 页就是正文的（纯答案册）不加** |
| L1 目录页 | 印刷目录首页 | 目录首页（有"目录/Contents"标题的页；无标题则取目录条目首行页） | 有印刷目录页**必须加且只加一条**；位置：封面、前置页之后，课/编/章之前 |
| L1 前置页 | 序言 / 前言 / 凡例 / 使用说明 / 图书使用说明 / 编写说明 | 对应页 | 目录正文之前独立成页的都要收；页首 3 行内出现关键词即识别 |
| L1 课 | 基础课 / 综合课（合订本特有的学科分组） | **整页分隔页** | 有分隔页必收；找不到分隔页才退而指向组内第一个学科 |
| L1 编/部分/学科/题型 | 第X编 / 上中下编 / 第X部分 / 学科名（刑法学、民法总则等）/ 题型名（简答题、案例分析题等） | **整页分隔页** | 优先指向整页大字分隔页；书签页码与分隔页相差 >1 页视为错，需修正 |
| L2 章 | 第X章 标题 | 章首页 | 标题与印刷目录一致 |
| L3 节 | 第X节 标题 | 节首页 | 挂在所属章下，不得跨章 |
| L1 附录/附件 | 附录一… / 附件一… / 宪法典全文等 | 对应页 | 与编/学科同级，置顶层末尾 |

**层级完整性自检口诀**：翻一遍书的整页大字分隔页，每一张都必须能在书签树里找到对应节点。

## 二、标题与文本规范

1. **以书面上印的字为准，不照抄文本层/OCR 的错字**。已知 cmap/OCR 错字对照：
   - `读职罪` → **渎职罪**（某刑法章节题集）
   - `综A课` → **综合课**（某答案分册分隔页）
   - `淫秒` → **淫秽**、`贪亏` → **贪污**（某 OCR 教材）
   - `第——编` → **第一编**、`抵嗯仁正`（p135 分隔页，实为"第五编 合同"）
2. 标题中的空格规范化：`第 X 章` → `第X章`；但保留词间必要空格（如"第一编 民法总则"）。
3. 书签标题不添加装饰（不用【】、不用页码后缀）。

---

## 三、页码指向规则

1. **整页分隔页优先**：凡书中有"整页大字"分隔页（页文本 ≤12 字，如"基础课""刑法分则""第五编 合同"），对应书签必须指向该分隔页，而不是第一个下级所在页。
2. **容差**：分隔页与下级首页相差 1 页（换章紧排）可接受；相差 ≥2 页必须修正为分隔页。
3. **无分隔页**：直接指向第一个下级（章/节）所在页。
4. 写入后全局展平页码必须单调不减（见红线 2）。

---

## 四、生成方法（按可靠性排序）

1. **印刷目录解析法（有文本层首选）**：解析目录页"第X章 标题…页码"，投票校准印刷页码→PDF页码偏移 delta；"标题出现在目标页"命中率 ≥50% 为校准有效，±2 窗口二次确认。
2. **顺序搜索法（页码不可靠/无页码时）**：先建全书页首文本索引（`ocr_index.py`），按目录顺序用"章号+标题"逐个匹配，游标单调前移。**禁止用"第X章"裸词兜底**（必乱）。
3. **倒序标题特判**：正文标题倒序的书（某系列"标题 第X章"），两种键序都试；分隔页用"整页文字≈名称"识别。
4. **扫描件 OCR 法**：每页即一张内嵌 JPEG，用 `ocr_lib.py` 直接取图 OCR，无需渲染库。目录页全页 OCR（scale 0.45）；校准锚点用页首条带（crop 0.2~0.35）省时。**不要相信 OCR 出的印刷页码**（27版法理学漂移 8 页），一律走方法 2。

---

## 五、验收红线（自动化检查，全过才算完成）

1. **层级正确**：子书签页码不得早于父书签页码 −1 页；不得跨章挂节
2. **页码单调**：全局展平后乱序数 = 0
3. **顶层不重复**：同名顶层书签不得重复
4. **条目来自目录**：书签与印刷目录逐条对应，不多不少（章以下抽查 + 章以上全查）
5. **分隔页全覆盖**：所有整页大字分隔页（页文本 ≤12 字）在书签树 ±1 页内都有对应节点
6. **前置页无遗漏**：序言/前言/使用说明等已收
7. **错字为零**：对照第二节对照表 + 抽查正文

工具：`audit2.py`（1~4、6）、短页分隔页扫描（5，见第八节）、`verify.py`（4 的目录比对）。

## 六、目录页与封面（收尾两件套）

- **封面**：`add_cover.py`——幂等，排在第 1 位
- **目录**：`add_catalog_link.py`——幂等，插在"第一个页号 ≥ 目录页的顶层项"之前
- 两脚本均 dry-run / `--write` 两档；写入前存书签 JSON 快照，写入后自动跑红线
- 注意：插入「目录」可能暴露**子节点跨过目录页**的结构问题（如"序言"下挂"绪论"p9 > 目录 p5）→ 把该子节点提升为顶层并对前导部分按页码重排

## 八、操作流程（每本书）

1. **备份**：小文件整本复制到 `_备份_删除前快照/pdf书签备份/`；大部头（>100MB）只存书签 JSON 快照
2. **探测**：`detect_tocpage.py` 定位目录页；短页扫描找全部分隔页
3. **生成**：按第四节方法排序选用
4. **收尾两件套**：封面 + 目录书签
5. **验收**：第五节红线 1~7 全过 + 抽 2~3 章人工核对
6. **登记**：更新 `进度台账_全量.md` 与 `done_list.json`

> 快照恢复方法：JSON 内是 `[[title, page0, children], ...]` 嵌套结构，用 `add_catalog_link.read_tree/rebuild` 即可重写回 PDF。

## 九、脚本索引（pdf_toc/）
